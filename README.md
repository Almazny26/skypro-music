# Skypro.Music

Курсовой проект — музыкальный плеер на Next.js. Можно слушать треки, добавлять в избранное, искать по названию и фильтровать по автору, жанру и году.

## Как запустить

Сначала установи зависимости:

```bash
npm install
```

Потом запусти сервер:

```bash
npm run dev
```

Открой в браузере http://localhost:3000

## Что внутри

- Next.js 15, React, TypeScript
- Redux для состояния плеера (текущий трек, плейлист)
- Запросы к API идут через прокси в папке app/api/proxy, чтобы обойти CORS
- Есть страницы: главная, подборки (плейлист дня, 100 танцевальных хитов, инди), избранное, вход и регистрация
- Поиск по названию, исполнителю, альбому и жанру. Фильтры по автору, жанру и году
- Плеер: play/pause, следующий/предыдущий, shuffle, repeat, перемотка, громкость
- Лайк и дизлайк (не рекомендовать) — лайк синхронизируется с сервером, дизлайк хранится локально
- Тосты вместо alert (react-toastify), лоадер при загрузке треков

## Скрипты

- `npm run dev` — запуск в режиме разработки
- `npm run build` — сборка
- `npm run start` — запуск собранного приложения
- `npm test` — тесты
